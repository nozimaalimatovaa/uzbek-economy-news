# Бесплатная версия: новости об экономике Узбекистана в Telegram

Эта версия ничего не стоит: без платного Anthropic API. Скрипт читает
RSS-ленты зарубежных СМИ (RFE/RL, EurasiaNet, The Diplomat, Reuters,
AKIpress, Trend News Agency), отбирает новости по ключевым словам
("Узбекистан" + экономические термины) и присылает список в Telegram.

## Отличие от версии с ИИ
- ✅ Полностью бесплатно (нет платы за API)
- ✅ Работает точно так же на GitHub Actions по расписанию
- ⚠️ Сводка — это список заголовков со ссылками, а не переписанное
  ИИ-резюме сути новости. Зато можно перейти по ссылке и прочитать
  полностью.
- ⚠️ Качество зависит от того, насколько хорошо ключевые слова ловят
  релевантные новости — иногда могут проскакивать нерелевантные или
  пропускаться релевантные, если журналисты не используют ожидаемые
  слова

## Что нужно подготовить

### 1. Telegram-бот (бесплатно)
- Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите
  **токен** (`TELEGRAM_BOT_TOKEN`)
- Напишите боту любое сообщение
- Узнайте **chat_id**: откройте
  `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` — найдите
  `"chat":{"id": ЧИСЛО}` — это `TELEGRAM_CHAT_ID`

### 2. Репозиторий на GitHub (бесплатно)
1. Создайте репозиторий (можно публичный — тогда Actions вообще без
   ограничений; можно и приватный — тоже бесплатный лимит минут в месяц
   более чем достаточен для одного запуска в день)
2. Загрузите файлы:
   - `news_digest_free.py`
   - `requirements-free.txt`
   - `.github/workflows/daily-news-free.yml`
3. **Settings → Secrets and variables → Actions** — добавьте 2 секрета:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`

Готово — работает каждый день бесплатно, без ключей и без счетов.

## Настройка под себя

Откройте `news_digest_free.py` и отредактируйте:

- **`FEEDS`** — список RSS-источников. Можно добавить любой другой
  зарубежный источник, у которого есть RSS-лента (например, Interfax,
  Silk Road Briefing, Caspian News и т.п.) — просто добавьте
  `"Название": "ссылка_на_rss"`.
- **`COUNTRY_KEYWORDS`** / **`ECONOMY_KEYWORDS`** — ключевые слова
  фильтрации. Добавляйте свои варианты, если что-то не ловится.
- **`HOURS_LOOKBACK`** — за сколько часов назад брать новости
  (по умолчанию 48 часов, с запасом на случай, если лента обновляется
  редко).

## Проверить вручную
GitHub → вкладка **Actions** → workflow "Daily Uzbekistan Economy News
Digest (Free)" → **Run workflow**.

## Локальный тест
```bash
pip install -r requirements-free.txt
export TELEGRAM_BOT_TOKEN="токен_бота"
export TELEGRAM_CHAT_ID="ваш_chat_id"
python news_digest_free.py
```

## Гибридный вариант (тоже бесплатно)
Если хочется красивое ИИ-резюме, но без затрат: можно вместо
Anthropic API использовать бесплатный тариф Google Gemini API
(есть щедрый бесплатный лимит запросов в день) — присылать туда
собранные заголовки и просить сделать сводку. Если хотите, могу
собрать и такой вариант.
